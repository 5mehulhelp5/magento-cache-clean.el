#+title: magento-cache-clean.el
#+author: Piotr Kwiecinski

Emacs integration for [[https://github.com/mage-os/magento-cache-clean][mage-os/magento-cache-clean]], a file watcher based cache cleaner for Magento 2.

* Features

- One-shot cache cleaning via =magento-cache-clean= (compilation buffer)
- Watch mode via =magento-cache-clean-watch= (comint; keys go straight to cache-clean)
- Transient UI via =magento-cache-clean-transient=
- Auto-detection of Magento root directory (=app/etc/env.php=)
- Works on remote projects (TRAMP, e.g. =/docker:=)
- One output buffer per Magento root
- Per-project configuration via =.dir-locals.el=
- Propagates =envrc= / =direnv= environment to child processes

* Requirements

- Emacs 30.1+
- [[https://github.com/mage-os/magento-cache-clean][cache-clean]] installed and on =PATH=

* Installation

** use-package with vc

#+begin_src emacs-lisp
(use-package magento-cache-clean
  :vc (:url "https://github.com/emacs-magento/magento-cache-clean.el"))
#+end_src

** Manual

Clone the repository and add it to your =load-path=:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/magento-cache-clean.el")
(require 'magento-cache-clean)
#+end_src

* Usage

** Transient interface

Run =M-x magento-cache-clean-transient= to open the transient UI where you can:

- Select verbosity level (silent / verbose / debug)
- Toggle =--keep-generated= and =--no-flood-guard= flags
- Pick a =--file-list= file
- Enter cache types to clean (comma-separated; any type name is accepted)
- Run a one-shot clean or start watch mode

Save defaults with =C-x s=; =M-x magento-cache-clean= and =M-x magento-cache-clean-watch= use them when called outside the menu.

** Direct commands

- =M-x magento-cache-clean= -- clean caches once
- =M-x magento-cache-clean-watch= -- start watch mode (comint)
- =M-x magento-cache-clean-watch-stop= -- stop the watcher
- =M-x magento-cache-clean-watch-restart= (or =M-x revert-buffer=) in a watch
  buffer -- restart it with the same arguments

From Lisp, pass cache-clean command line arguments:

#+begin_src emacs-lisp
(magento-cache-clean '("--keep-generated" "layout"))
(magento-cache-clean-watch '("--no-flood-guard"))
#+end_src

** Watch mode hotkeys

In the watch buffer, every printable key is sent straight to cache-clean,
which handles it as a hotkey. cache-clean prints the list of hotkeys when
the watcher starts; see the [[https://github.com/mage-os/magento-cache-clean#hotkeys][upstream README]] for details.

=C-c C-c= stops the watcher.

* Customization

| Variable                                 | Description                                 | Default         |
|------------------------------------------+---------------------------------------------+-----------------|
| =magento-cache-clean-executable=         | Path to the cache-clean binary              | ="cache-clean"= |
| =magento-cache-clean-directory=          | Magento root (nil = auto-detect)            | =nil=           |
| =magento-cache-clean-error-regexp-alist= | Regexps that make one-shot output clickable | =nil=           |

=magento-cache-clean-directory= is safe for use in =.dir-locals.el=:

#+begin_src emacs-lisp
((nil . ((magento-cache-clean-directory . "/path/to/magento"))))
#+end_src

=magento-cache-clean-executable= is not marked safe, since a
=.dir-locals.el= could otherwise run any program.  Emacs asks before
applying it; answer =!= to remember the value.
